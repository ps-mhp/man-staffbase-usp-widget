# Ustawienia

| Ustawienie | Opis |
| --- | --- |
| Układ (zakładka „Wygląd”) | Dwukolumnowy (domyślny), kafelki, znaczniki na polu, pasek linii, kolumna kolorów, pasek kolorów, nagłówek pytania z paskiem. Zmiana zachowuje wszystkie teksty. |
| Akcent (zakładka „Wygląd”) | Czerwony (domyślnie), szary lub niebieski — kolory identyfikacji wizualnej MAN. |
| Pokaż ikony (zakładka „Wygląd”) | Włączone (domyślnie). Wyłączenie powoduje ukrycie wszystkich ikon; opcja „Zaznaczenie na polu” powoduje wówczas wyświetlanie zaznaczenia wszędzie. |
| Tryb kreatora (zakładka „Zachowanie”) | Wyłączony (domyślnie). Włączenie powoduje wyświetlenie paska nad polem, za pomocą którego czytelnicy mogą samodzielnie zmieniać układ, kolor i ikony oraz natychmiast zobaczyć wynik. Wybór dotyczy wyłącznie bieżącego widoku i nie jest zapisywany; opcja „Resetuj” przywraca ustawioną wersję. |
| Wiersz powyżej (zakładka „Treść”) | Opcjonalnie, krótki wiersz nad nagłówkiem. |
| Nagłówek (zakładka „Treść”) | Pytanie lub tytuł ramki. |
| Punkty (lista po lewej) | Maksymalnie osiem. W każdym punkcie **słowo kluczowe**, opcjonalnie **objaśnienie** i **ikona**. Punkt bez tekstu nie jest wyświetlany. |
