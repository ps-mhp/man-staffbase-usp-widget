# Ustawienia

| Ustawienie | Opis |
| --- | --- |
| Układ | Dwukolumnowy (domyślny), kafelki, znaczniki na polu, pasek liniowy, kolumna kolorów, pasek kolorów, nagłówek z pytaniem i paskiem. Zmiana zachowuje wszystkie teksty. |
| Kolor akcentujący | Czerwony (domyślny), szary lub niebieski — kolory identyfikacji wizualnej MAN. |
| Pokaż symbole | Włączone (domyślnie). Wyłączenie powoduje ukrycie wszystkich symboli; opcja „Zaznaczenie na polu” powoduje wówczas wyświetlanie zaznaczenia wszędzie. |
| Wiersz powyżej | Opcjonalnie, krótki wiersz nad nagłówkiem. |
| Nagłówek | Pytanie lub tytuł ramki. |
| Punkty | Do ośmiu. W każdym punkcie **słowo kluczowe**, opcjonalnie **objaśnienie** i **symbol**. Punkt bez tekstu nie jest wyświetlany. |
