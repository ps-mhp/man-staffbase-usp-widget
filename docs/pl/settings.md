# Ustawienia

| Ustawienie | Opis |
| --- | --- |
| Układ | Dwukolumnowy (domyślny), kafelki, znaczniki na polu, pasek linii, kolumna kolorów, pasek kolorów, nagłówek z pytaniem i paskiem. Zmiana zachowuje wszystkie teksty. |
| Kolor akcentujący | Czerwony (domyślny), szary lub niebieski — kolory MAN-CI. |
| Pokaż symbole | Włączone (domyślnie). Wyłączenie ukrywa wszystkie symbole; opcja „Zaznaczenie na polu” powoduje wówczas wyświetlanie zaznaczenia wszędzie. |
| Tryb kreatora | Wyłączony (domyślnie). Włączenie powoduje wyświetlenie paska nad polem, za pomocą którego czytelnicy mogą samodzielnie zmieniać układ, kolor i symbole oraz natychmiast zobaczyć wynik. Wybór dotyczy tylko ich własnego widoku i nie jest zapisywany; opcja „Resetuj” przywraca ustawioną wersję. |
| Wiersz powyżej | Opcjonalnie, krótki wiersz nad nagłówkiem. |
| Nagłówek | Pytanie lub tytuł ramki. |
| Punkty | Maksymalnie osiem. W każdym punkcie **słowo kluczowe**, opcjonalnie **objaśnienie** i **symbol**. Punkt bez tekstu nie jest wyświetlany. |
