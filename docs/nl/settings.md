# Instellingen

| Instelling | Beschrijving |
| --- | --- |
| Lay-out | Twee kolommen (standaard), tegels, vinkjes op vlak, lijnbalk, kleurkolom, kleurenband, vraagkop met balk. Bij het wisselen blijft alle tekst behouden. |
| Accentkleur | Rood (standaard), grijs of blauw — de kleuren van de MAN-CI. |
| Symbolen weergeven | Aan (standaard). Uit verbergt alle symbolen; bij „Vinkje op vlak“ wordt dan overal het vinkje weergegeven. |
| Regel erboven | Optioneel, een korte regel boven de kop. |
| Kop | De vraag of de titel van het kader. |
| Punten | Maximaal acht. Per punt **trefwoord**, optioneel **toelichting** en **symbool**. Een punt zonder tekst wordt niet weergegeven. |
