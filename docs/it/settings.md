# Impostazioni

| Impostazione | Descrizione |
| --- | --- |
| Layout (scheda «Aspetto») | A due colonne (impostazione predefinita), a riquadri, caselle su sfondo, caselle con linea di intestazione, barra con linee, colonna colorata, nastro colorato, intestazione con barra. Il cambio di layout mantiene tutti i testi. |
| Colore di risalto (scheda «Aspetto») | Rosso (impostazione predefinita), grigio o blu — i colori della MAN-CI. |
| Mostra icone (scheda «Aspetto») | Attivo (impostazione predefinita). Disattivato nasconde tutte le icone; gli elenchi a spunta mostrano quindi ovunque il segno di spunta, mentre l’opzione «Segno di spunta con linea superiore» non mostra alcun segno sopra la domanda. |
| Modalità Builder (scheda «Comportamento») | Disattivata (impostazione predefinita). Attivata, mostra una barra sopra la casella che consente ai lettori di modificare autonomamente layout, colore e icone e di vedere immediatamente il risultato. La scelta vale solo per la propria visualizzazione e non viene salvata; «Ripristina» riporta alla versione predefinita. |
| Riga sopra (scheda «Contenuto») | Facoltativa, una breve riga sopra il titolo. |
| Simbolo sopra il titolo (scheda «Contenuto») | Solo con «Spunta con linea di intestazione»: un’icona MAN in colore di risalto sopra la domanda. Facoltativo. |
| Titolo (scheda «Contenuto») | La domanda o il titolo del riquadro. |
| Punti (elenco a sinistra) | Fino a otto. Per ogni punto: **parola chiave**, facoltativamente **spiegazione** e **icona**. La spiegazione può contenere paragrafi, interruzioni di riga (Shift+Invio) ed elenchi puntati (pulsante «Elenco puntato» o «- » all’inizio della riga). Un punto senza testo non viene visualizzato. |
