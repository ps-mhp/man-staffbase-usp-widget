# Impostazioni

| Impostazione | Descrizione |
| --- | --- |
| Layout | A due colonne (impostazione predefinita), riquadri, segno di spunta su area, barra con linee, colonna colorata, nastro colorato, intestazione con barra. Al cambio di layout, tutti i testi vengono mantenuti. |
| Colore di risalto | Rosso (predefinito), grigio o blu — i colori della MAN-CI. |
| Mostra simboli | Attivo (predefinito). Disattivando questa opzione, tutti i simboli vengono nascosti; l’opzione «Spunta sull’area» mostra quindi la spunta ovunque. |
| Modalità Builder | Disattivata (impostazione predefinita). Se attivata, visualizza una barra sopra il riquadro che consente ai lettori di modificare autonomamente il layout, il colore e le icone e di vedere immediatamente il risultato. La scelta vale solo per la propria visualizzazione e non viene salvata; «Ripristina» riporta alla versione predefinita. |
| Riga sopra | Facoltativa, una breve riga sopra il titolo. |
| Titolo | La domanda o il titolo del riquadro. |
| Punti | Fino a otto. Per ogni punto: **parola chiave**, facoltativamente **spiegazione** e **simbolo**. Un punto senza testo non viene visualizzato. |
