# Impostazioni

| Impostazione | Descrizione |
| --- | --- |
| Layout (scheda «Aspetto») | A due colonne (impostazione predefinita), a riquadri, spunta su area, barra di linea, colonna di colore, nastro di colore, intestazione con barra. Il cambio di layout mantiene tutti i testi. |
| Accento (scheda «Design») | Rosso (impostazione predefinita), grigio o blu — i colori della MAN-CI. |
| Mostra icone (scheda «Design») | Attivo (impostazione predefinita). Disattivando questa opzione, tutte le icone vengono nascoste; «Spunta su area» mostra quindi la spunta ovunque. |
| Modalità Builder (scheda «Comportamento») | Disattivata (impostazione predefinita). Se attivata, mostra una barra sopra la casella che consente ai lettori di modificare autonomamente layout, colore e icone e di vedere immediatamente il risultato. La scelta vale solo per la propria visualizzazione e non viene salvata; «Ripristina» riporta alla versione predefinita. |
| Riga sopra (scheda «Contenuto») | Opzionale, una breve riga sopra il titolo. |
| Titolo (scheda «Contenuto») | La domanda o il titolo del riquadro. |
| Punti (elenco a sinistra) | Fino a otto. Per ogni punto: **parola chiave**, facoltativamente **spiegazione** e **icona**. Un punto senza testo non viene visualizzato. |
