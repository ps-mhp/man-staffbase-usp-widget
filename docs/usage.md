# Schritt für Schritt

1. Fügen Sie die **USP-Box** auf der Seite ein. Der Editor öffnet sich.
2. Wählen Sie eine **Gestaltung** und eine **Akzentfarbe**.
3. Tragen Sie unter **Kopf** die **Überschrift** ein, etwa „Was bringt's dem
   Kunden?“, und bei Bedarf eine **Zeile darüber**, etwa „Kundennutzen“.
4. Klicken Sie auf **Punkt hinzufügen** und tragen Sie **Stichwort** und
   optional **Erläuterung** ein. Wiederholen Sie das für jeden Vorteil (bis zu
   acht; drei bis vier lesen sich am besten).
5. Optional: **Symbol wählen** öffnet das Raster der MAN-Symbole. Die Suche
   findet deutsche Namen, z. B. „Lkw“ oder „Kalender“.
6. Ordnen Sie die Punkte mit ↑ und ↓.
7. Klicken Sie auf **Übernehmen** und speichern Sie die Seite.
