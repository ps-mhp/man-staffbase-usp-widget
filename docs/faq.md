# FAQ

**Frage:** Die Box erscheint auf der Seite nicht.

Antwort: Sie braucht mindestens einen Punkt mit Stichwort oder Erläuterung.
Eine Überschrift allein wird nicht gezeigt.

**Frage:** Ein Symbol fehlt, wo eines gewählt ist.

Antwort: Die Zeichnungen der Symbole lädt die Box kurz nach dem Text nach.
Laden Sie die Seite neu. Fehlt das Symbol weiter, melden Sie es mit Seite und
Name des Symbols.

**Frage:** Ich habe im Builder eine Gestaltung gewählt, nach dem Neuladen ist
sie weg.

Antwort: Der Builder ist eine Vorschau für Leser:innen und speichert nichts.
Um die Box dauerhaft umzustellen, öffnen Sie sie im Editor und wählen dort
Gestaltung und Farbe.

**Frage:** Werden die Texte mit übersetzt?

Antwort: Ja. Überschrift, Zeile darüber, Stichworte und Erläuterungen laufen
durch die Inhaltsübersetzung; Gestaltung, Farbe und Symbole bleiben gleich.
