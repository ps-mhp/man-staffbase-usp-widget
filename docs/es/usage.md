# Paso a paso

1. Inserta el **recuadro USP** en la página. Se abrirá el editor.
2. Elige un **diseño** y un **color de contraste**.
3. En el campo **Encabezado**, introduce el **título**, por ejemplo, «¿Qué ventajas tiene para el
   cliente?», y, si es necesario, una **línea encima**, por ejemplo, «Ventajas para el cliente».
4. Haz clic en **Añadir punto** e introduce una **palabra clave** y,
   opcionalmente, una **explicación**. Repite este proceso para cada ventaja (hasta
   ocho; lo ideal es que haya entre tres y cuatro).
5. Opcional: **Seleccionar símbolo** abre la lista de símbolos de MAN. La búsqueda
   encuentra nombres en alemán, p. ej., «Lkw» o «Kalender».
6. Ordene los puntos con ↑ y ↓.
7. Haga clic en **Aplicar** y guarde la página.
