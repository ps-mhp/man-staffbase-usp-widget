# Configuración

| Configuración | Descripción |
| --- | --- |
| Diseño (pestaña «Diseño») | Dos columnas (predeterminado), mosaicos, casillas en el área de trabajo, barra de líneas, columna de colores, banda de colores, encabezado de pregunta con barra. Al cambiar de diseño se conservan todos los textos. |
| Color de destaque (pestaña «Diseño») | Rojo (predeterminado), gris o azul —los colores de la identidad corporativa de MAN—. |
| Mostrar iconos (pestaña «Diseño») | Activado (predeterminado). Si se desactiva, se ocultan todos los iconos; «Marca de verificación en el área» muestra entonces la marca de verificación en todas partes. |
| Modo Builder (pestaña «Comportamiento») | Desactivado (predeterminado). Activado muestra una barra sobre el cuadro con la que los lectores pueden cambiar ellos mismos el diseño, el color y los iconos, y ver el resultado al instante. La selección solo se aplica a su propia vista y no se guarda; «Restablecer» vuelve a la versión configurada. |
| Línea superior (pestaña «Contenido») | Opcional, una breve línea encima del título. |
| Título (pestaña «Contenido») | La pregunta o el título del recuadro. |
| Puntos (lista a la izquierda) | Hasta ocho. Por cada punto, **palabra clave**, opcionalmente **explicación** e **icono**. No se muestra un punto sin texto. |
