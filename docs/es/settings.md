# Configuración

| Configuración | Descripción |
| --- | --- |
| Diseño | Dos columnas (predeterminado), mosaicos, casillas de selección en el área, barra de líneas, columna de colores, banda de colores, encabezado de preguntas con barra. Al cambiar de diseño, se conservan todos los textos. |
| Color de contraste | Rojo (predeterminado), gris o azul —los colores de la identidad corporativa de MAN—. |
| Mostrar iconos | Activado (predeterminado). Si se desactiva, se ocultan todos los iconos; en ese caso, la opción «Marca de verificación en el área» muestra la marca de verificación en todas partes. |
| Línea superior | Opcional, una línea breve encima del título. |
| Título | La pregunta o el título del recuadro. |
| Puntos | Hasta ocho. Por cada punto, **palabra clave**, opcionalmente **explicación** y **símbolo**. No se muestra un punto sin texto. |
