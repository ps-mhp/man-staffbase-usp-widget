# Passo a passo

1. Insira a **caixa USP** na página. O editor abre-se.
2. Escolha um **design** e uma **cor de destaque**.
3. Em **Título**, introduza o **título**, por exemplo, «Quais são as vantagens para o
   cliente?», e, se necessário, uma **linha acima**, por exemplo, «Vantagens para o cliente».
4. Clique em **Adicionar ponto** e introduza a **palavra-chave** e,
   opcionalmente, a **explicação**. Repita este processo para cada vantagem (até
   oito; três a quatro são as que melhor se leem).
5. Opcional: **Selecionar ícone** abre a grelha de ícones MAN. A pesquisa
   encontra nomes em alemão, por exemplo, «Lkw» ou «Kalender».
6. Organize os pontos com ↑ e ↓.
7. Clique em **Aplicar** e guarde a página.
