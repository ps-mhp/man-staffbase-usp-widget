# Configurações

| Configuração | Descrição |
| --- | --- |
| Layout | Duas colunas (padrão), mosaicos, caixas de seleção na área, barra de linhas, coluna de cores, faixa de cores, cabeçalho de perguntas com barra. Ao alterar o layout, todos os textos são mantidos. |
| Cor de destaque | Vermelho (padrão), cinzento ou azul — as cores da MAN-CI. |
| Mostrar símbolos | Ativado (padrão). Desativado oculta todos os símbolos; «Marca de seleção na área» mostra então a marca de seleção em todo o lado. |
| Modo Construtor | Desativado (predefinição). Ativado mostra uma barra acima da caixa, com a qual os leitores podem alterar eles próprios o design, a cor e os símbolos e ver o resultado imediatamente. A escolha aplica-se apenas à sua própria visualização e não é guardada; «Repor» volta à versão predefinida. |
| Linha acima | Opcional, uma linha curta acima do título. |
| Título | A pergunta ou o título da caixa. |
| Pontos | Até oito. Por ponto: **palavra-chave**, opcionalmente **explicação** e **símbolo**. Um ponto sem texto não é apresentado. |
