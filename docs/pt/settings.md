# Definições

| Definição | Descrição |
| --- | --- |
| Layout (separador «Apresentação») | Duas colunas (predefinição), mosaicos, caixas de seleção, barra de linhas, coluna de cores, faixa de cores, cabeçalho de perguntas com barra. Ao alterar o layout, todos os textos são mantidos. |
| Destaque (separador «Design») | Vermelho (padrão), cinzento ou azul — as cores da MAN-CI. |
| Mostrar ícones (separador «Design») | Ativado (padrão). Desativado oculta todos os ícones; «Caixa de seleção na área» mostra então a caixa de seleção em todo o lado. |
| Modo Construtor (separador «Comportamento») | Desativado (predefinição). Ativado mostra uma barra acima da caixa, com a qual os leitores podem alterar eles próprios o design, a cor e os ícones e ver o resultado imediatamente. A escolha aplica-se apenas à sua própria visualização e não é guardada; «Repor» volta à versão predefinida. |
| Linha acima (separador «Conteúdo») | Opcional, uma linha curta acima do título. |
| Título (separador «Conteúdo») | A pergunta ou o título da caixa. |
| Pontos (lista à esquerda) | Até oito. Por ponto: **palavra-chave**, opcionalmente **explicação** e **ícone**. Um ponto sem texto não é apresentado. |
