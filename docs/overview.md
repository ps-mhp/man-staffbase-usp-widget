# USP-Box

Die USP-Box fasst die Vorteile eines Produkts oder Angebots in wenigen Punkten
zusammen: eine Frage wie „Was bringt's dem Kunden?“ und darunter oder daneben
die Antworten, jeweils als Stichwort mit kurzer Erläuterung und auf Wunsch mit
einem Symbol aus der MAN-Symbolschrift.

## Was Leser:innen sehen

Je nach gewählter **Gestaltung** eine von sieben Formen: zweispaltig, Kacheln,
Häkchen auf Fläche, Linienleiste, Farbspalte, Farbband oder Fragekopf mit
Leiste. Die **Akzentfarbe** (Rot, Grau oder Blau) färbt Linien, Flächen und
Symbole. Auf dem Telefon stapeln sich alle Gestaltungen zu einer Spalte.

Ohne Punkte erscheint die Box nicht.

Im **Builder-Modus** steht über der Box eine Leiste mit Gestaltung, Farbe und
Symbolen. Leser:innen schalten damit selbst um und sehen das Ergebnis sofort —
gedacht für Seiten, auf denen die Box vorgestellt oder abgestimmt wird.
Gespeichert wird dabei nichts.

## Was Sie im CMS-Editor sehen

Der Editor zeigt rechts eine Vorschau der Box. Sie entspricht der Seite; nur
die Breite hängt vom Dialog ab.
