# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Layout (Reiter „Gestaltung“) | Zweispaltig (Vorgabe), Kacheln, Häkchen auf Fläche, Häkchen mit Kopflinie, Linienleiste, Farbspalte, Farbband, Fragekopf mit Leiste. Ein Wechsel behält alle Texte. |
| Akzent (Reiter „Gestaltung“) | Rot (Vorgabe), Grau oder Blau — die Farben der MAN-CI. |
| Icons zeigen (Reiter „Gestaltung“) | An (Vorgabe). Aus blendet alle Icons aus; die Häkchenlisten zeigen dann überall das Häkchen, „Häkchen mit Kopflinie“ kein Zeichen über der Frage. |
| Builder-Modus (Reiter „Verhalten“) | Aus (Vorgabe). An zeigt über der Box eine Leiste, mit der Leser:innen Gestaltung, Farbe und Icons selbst umschalten und das Ergebnis sofort sehen. Die Wahl gilt nur für ihre eigene Ansicht und wird nicht gespeichert; „Zurücksetzen“ kehrt zur eingestellten Fassung zurück. |
| Zeile darüber (Reiter „Inhalt“) | Optional, eine kurze Zeile über der Überschrift. |
| Zeichen über der Überschrift (Reiter „Inhalt“) | Nur bei „Häkchen mit Kopflinie“: ein Icon aus der Icon-Bibliothek in Akzentfarbe über der Frage. Optional. |
| Überschrift (Reiter „Inhalt“) | Die Frage oder der Titel der Box. |
| Punkte (Liste links) | Bis zu acht. Je Punkt **Stichwort**, optional **Erläuterung** und **Icon**. Die Erläuterung kann Absätze, Zeilenumbrüche (Umschalt+Enter) und Aufzählungen enthalten (Knopf „Aufzählung“ oder „- “ am Zeilenanfang). Ein Punkt ohne Text wird nicht gezeigt. |
