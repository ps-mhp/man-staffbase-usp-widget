# Einstellungen

| Einstellung | Beschreibung |
| --- | --- |
| Gestaltung | Zweispaltig (Vorgabe), Kacheln, Häkchen auf Fläche, Linienleiste, Farbspalte, Farbband, Fragekopf mit Leiste. Ein Wechsel behält alle Texte. |
| Akzentfarbe | Rot (Vorgabe), Grau oder Blau — die Farben der MAN-CI. |
| Symbole zeigen | An (Vorgabe). Aus blendet alle Symbole aus; „Häkchen auf Fläche“ zeigt dann überall das Häkchen. |
| Zeile darüber | Optional, eine kurze Zeile über der Überschrift. |
| Überschrift | Die Frage oder der Titel der Box. |
| Punkte | Bis zu acht. Je Punkt **Stichwort**, optional **Erläuterung** und **Symbol**. Ein Punkt ohne Text wird nicht gezeigt. |
