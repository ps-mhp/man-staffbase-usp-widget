# Settings

| Setting | Description |
| --- | --- |
| Layout | Two-column (default), tiles, checkmarks on area, line bar, color column, color bar, question header with bar. Changing the layout preserves all text. |
| Accent Color | Red (default), gray, or blue—the colors of the MAN CI. |
| Show Icons | On (default). Off hides all icons; “Checkmark on Area” then displays the checkmark everywhere. |
| Line above | Optional; a short line above the heading. |
| Heading | The question or title of the box. |
| Bullets | Up to eight. For each bullet: **keyword**, optional **explanation**, and **icon**. A bullet without text is not displayed. |
