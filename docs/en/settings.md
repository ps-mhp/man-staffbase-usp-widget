# Settings

| Setting | Description |
| --- | --- |
| Layout | Two-column (default), tiles, checkmarks on area, line bar, color column, color strip, question header with bar. Changing the layout preserves all text. |
| Accent Color | Red (default), gray, or blue—the colors of the MAN CI. |
| Show Icons | On (default). Off hides all icons; “Checkmark on Area” then displays the checkmark everywhere. |
| Builder Mode | Off (default). On displays a bar above the box that allows readers to toggle layout, color, and icons themselves and see the result immediately. The selection applies only to their own view and is not saved; “Reset” returns to the preset version. |
| Line Above | Optional; a short line above the heading. |
| Heading | The question or title of the box. |
| Bullets | Up to eight. Each bullet includes a **keyword**, an optional **explanation**, and a **symbol**. A bullet with no text is not displayed. |
