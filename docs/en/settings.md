# Settings

| Setting | Description |
| --- | --- |
| Layout (Design tab) | Two-column (default), Tiles, Checkmarks on Area, Line Bar, Color Column, Color Bar, Question Header with Bar. Changing the layout preserves all text. |
| Accent (Design tab) | Red (default), gray, or blue—the colors of the MAN CI. |
| Show Icons (Design tab) | On (default). Off hides all icons; “Checkmark on Area” then displays the checkmark everywhere. |
| Builder Mode (Behavior tab) | Off (default). On displays a bar above the box that allows readers to toggle layout, color, and icons themselves and see the result immediately. This setting applies only to your own view and is not saved; “Reset” returns to the default version. |
| Line above (Content tab) | Optional: a short line above the headline. |
| Heading (the “Content” tab) | The question or title of the box. |
| Bullets (list on the left) | Up to eight. For each bullet: **keyword**, optional **explanation**, and **icon**. A bullet without text is not displayed. |
