# Settings

| Setting | Description |
| --- | --- |
| Layout (Design tab) | Two-column (default), Tiles, Checkmarks on Area, Checkmarks with Header Line, Line Bar, Color Column, Color Bar, Question Header with Bar. Changing the layout preserves all text. |
| Accent (Design tab) | Red (default), gray, or blue—the MAN CI colors. |
| Show icons (Design tab) | On (default). Off hides all icons; checkbox lists then display the checkmark everywhere, while “Checkmark with header line” shows no symbol above the question. |
| Builder Mode (Behavior tab) | Off (default). On displays a bar above the box that allows readers to toggle the design, color, and icons themselves and see the result immediately. The selection applies only to their own view and is not saved; “Reset” returns to the default version. |
| Line Above (the “Content” tab) | Optional: a short line above the heading. |
| Icon above the heading (Content tab) | Only if “Checkmark with header line” is selected: a MAN icon in an accent color above the question. Optional. |
| Heading (Content tab) | The question or title of the box. |
| Bullets (list on the left) | Up to eight. For each bullet: **keyword**, optional **explanation**, and **icon**. The explanation can contain paragraphs, line breaks (Shift+Enter), and bulleted lists (the “Bulleted List” button or “- ” at the beginning of a line). A bullet point without text is not displayed. |
