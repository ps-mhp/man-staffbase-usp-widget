# FAQ

**Question:** The box does not appear on the page.

Answer: It requires at least one item with a keyword or explanation.
A heading alone will not be displayed.

**Question:** There is an empty box instead of an icon.

Answer: The MAN icon font comes from the instance’s theme; the box includes
a copy of it in case it’s missing. Reload the page. If the empty box persists,
report it, including the page and the icon name.

**Question:** Are the texts translated as well?

Answer: Yes. The heading, the line above it, keywords, and explanations go
through the content translation; the layout, color, and icons remain the same.
