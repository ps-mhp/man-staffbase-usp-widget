# Step by Step

1. Insert the **USP box** onto the page. The editor will open.
2. Select a **design** and an **accent color**.
3. Under **Header**, enter the **headline**, such as “What’s in it for the
   customer?”, and, if needed, a **line above it**, such as “Customer benefits.”
4. Click **Add Point** and enter a **keyword** and,
   optionally, an **explanation**. Repeat this for each benefit (up to
   eight; three to four read best).
5. Optional: **Select Icon** opens the MAN icon grid. The search
   finds German names, such as “Lkw” or “Kalender.”
6. Rearrange the bullet points using ↑ and ↓.
7. Click **Apply** and save the page.
