# USP Box

The USP Box summarizes the benefits of a product or offer in a few points:
a question such as “What’s in it for the customer?” and below or next to it
the answers, each as a keyword with a brief explanation and, if desired, with
a symbol from the MAN symbol set.

## What Readers See

Depending on the chosen **design**, one of seven formats: two-column, tiles,
checkmarks on a background, a line bar, a color column, a color band, or a question header with
a bar. The **accent color** (red, gray, or blue) colors lines, backgrounds, and
symbols. On mobile devices, all layouts stack into a single column.

Without points, the box does not appear.

## What You See in the CMS Editor

The editor displays a preview of the box on the right. It matches the page; only
the width depends on the dialog.
