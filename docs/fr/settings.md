# Paramètres

| Paramètre | Description |
| --- | --- |
| Mise en page (onglet « Mise en page ») | Deux colonnes (par défaut), mosaïque, coche sur fond, barre de lignes, colonne de couleurs, bande de couleurs, en-tête de question avec barre. Le changement de mise en page conserve tous les textes. |
| Accent (onglet « Mise en page ») | Rouge (par défaut), gris ou bleu — les couleurs de l’identité visuelle de MAN. |
| Afficher les icônes (onglet « Mise en page ») | Activé (par défaut). Désactivé masque toutes les icônes ; « Coche sur la zone » affiche alors la coche partout. |
| Mode Builder (onglet « Comportement ») | Désactivé (par défaut). Activé affiche une barre au-dessus de la zone, permettant aux lecteurs de modifier eux-mêmes la mise en page, la couleur et les icônes, et de voir immédiatement le résultat. Ce choix ne s'applique qu'à votre propre affichage et n'est pas enregistré ; « Réinitialiser » permet de revenir à la version par défaut. |
| Ligne au-dessus (onglet « Contenu ») | Facultatif : une courte ligne au-dessus du titre. |
| Titre (onglet « Contenu ») | La question ou le titre de l'encadré. |
| Points (liste à gauche) | Jusqu’à huit. Pour chaque point : **mot-clé**, éventuellement **explication** et **icône**. Un point sans texte n’est pas affiché. |
