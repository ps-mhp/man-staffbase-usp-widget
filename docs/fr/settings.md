# Paramètres

| Paramètre | Description |
| --- | --- |
| Mise en page | Deux colonnes (par défaut), vignettes, coche sur la zone, barre de lignes, colonne de couleur, bande de couleur, en-tête de question avec barre. Le changement de mise en page conserve tous les textes. |
| Couleur d'accent | Rouge (par défaut), gris ou bleu — les couleurs de l'identité visuelle de MAN. |
| Afficher les icônes | Activé (par défaut). Désactivé masque toutes les icônes ; l'option « Coche sur la zone » affiche alors la coche partout. |
| Ligne au-dessus | Facultatif, une courte ligne au-dessus du titre. |
| Titre | La question ou le titre de l’encadré. |
| Points | Jusqu’à huit. Par point : **mot-clé**, éventuellement **explication** et **symbole**. Un point sans texte n’est pas affiché. |
